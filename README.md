# claude-commit

Настройки, плагины и память Claude Code.

## Установленные плагины и маркетплейсы

- **andrej-karpathy-skills** — поведенческие принципы написания чистого кода по Андрею Карпати  
  Источник: https://github.com/multica-ai/andrej-karpathy-skills

## Содержимое

- `CLAUDE.md` — глобальные инструкции для Claude (правила Карпати)
- `commands/` — пользовательские slash-команды
- `memory/` — память Claude о пользователе и настройках
- `plugins/` — список установленных плагинов и настройки
