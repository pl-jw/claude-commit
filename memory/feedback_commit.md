После завершения любой задачи всегда делать commit и push на GitHub.

**Why:** Пользователь хочет, чтобы все изменения сразу сохранялись в репозитории.

**How to apply:** После каждого изменения файлов — git add, git commit, git push. Не ждать отдельной просьбы.
